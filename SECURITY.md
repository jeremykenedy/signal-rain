# Security

Version 1.0.x is the supported release line. Report a vulnerability privately through GitHub security advisories for this repository. Do not include private keys, passwords, device addresses, or personal information in public reports.

The application requires no network permission and has no runtime dependencies. Installer downloads use HTTPS, repository-bound release URLs, a constrained redirect allowlist, and published SHA-256 verification. Checksums detect corrupted downloads; release trust still depends on the repository and the signing key.
