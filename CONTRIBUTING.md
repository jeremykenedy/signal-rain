# Contributing

Keep changes focused and preserve package identity, the settings-provider contract, and upgrade signing continuity. New scene controls must be useful, validated and documented. Do not add network calls, telemetry, advertising, readable scene text or watermarks.

Run `bash test.sh`, both coverage scripts, the documentation/privacy checks, and `bash build.sh`. Run the scene and remote settings on an Android TV emulator or target hardware and inspect every screenshot after capture. Report device gaps accurately. Preserve license and NOTICE obligations for any redistributed material.
