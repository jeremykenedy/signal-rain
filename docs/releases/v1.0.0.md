# Signal Rain 1.0.0

First release of an original animated abstract digital-rain screensaver.

## Breaking changes

None. This is the initial release.

## Major and minor additions

- Android DreamService and full-screen animated preview for API 23 and newer.
- Remote-friendly density, speed, palette, glow, and geometric mark controls.
- Per-setting randomization, randomize-all, and validated host settings provider.
- Signed APK, checksum-verified install/update/uninstall commands, and documentation.
- No app network permission, tracking, analytics, reporting, ads, words, or watermarks.

## Commands and upgrade path

Install with `python3 install.py --serial TV_IP:5555`. Use the same command to update without removing saved preferences. `--apk` selects a local signed APK, `--yes` confirms unattended installation, and `--uninstall` removes this package only. Select Signal Rain in the TV screensaver settings separately.

Keep the application ID and original signing key for future upgrades. API 23 is the minimum supported Android version. Android TV emulator behavior is verified; physical Fire TV, Android TV, Google TV, native 4K, idle activation, and reboot persistence remain unverified.
